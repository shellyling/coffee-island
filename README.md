# 咖啡地圖島

咖啡的世界：用 3D 六邊形群島介紹手沖、咖啡豆、風味、拉花、咖啡廳、咖啡師、產區、器材與烘焙。點一座島，鏡頭會飛過去並打開介紹卡片。

整個網站只有一個 `index.html`，3D 套件（Three.js 0.147）從 jsDelivr CDN 載入，不需要伺服器或建置步驟。

## 放上 GitHub Pages

1. 在 GitHub 建立新的 repository，例如 `coffee-island`
2. 上傳 `index.html` 和 `README.md`
3. 到 **Settings → Pages**，Source 選 **Deploy from a branch**，分支選 `main`、資料夾選 `/ (root)`，按 Save
4. 約一兩分鐘後網址會出現在同一頁：`https://<你的帳號>.github.io/coffee-island/`

之後修改只要重新上傳 `index.html`，GitHub Pages 會自動更新。

## 修改內容

打開 `index.html`，搜尋「內容資料：日後只要改這裡」：

- `SITE`：網站標題與副標
- `ISLANDS`：每座島的名稱、顏色、簡介、標籤（chips）與重點（points）
  - `at`：島的位置。`[0]`～`[5]` 是繞中央島的第一圈，`[0, 1]` 代表在 0 號與 1 號之間的外圈
  - 相鄰的島會自動架橋
- `LINKS`：島與島之間的關聯線與說明

每座島也有自己的分享連結，例如 `…/coffee-island/#latte-art` 會直接打開拉花島。

## 功能

- 9 座主題島 + 中央燈塔起點島，18 座木橋相連
- 島間關聯線、清單模式、手沖計時器（依粉量與粉水比自動計算水量與分段注水）
- 23 位角色過橋串門子：男生、女生、小孩、慢跑青少年、狗、貓、狐狸、大熊、小熊貓、外送員（機車與步行）
- 海洋：波浪、淺灘、浪花、魚群、海龜、海豚、鯊魚、鯨魚、運豆小船
- 天空：小鳥群、老鷹、飛機（凝結尾與防撞燈）、雲、晚霞
- 時間：自動（依當地時間）、白天、夕陽、黃昏；各類燈光有不同的橘黃色與閃爍方式
- 支援深色模式與「減少動態效果」設定
